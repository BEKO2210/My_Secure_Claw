# learnings/

The bot's structured learning loop. **Bot writes here, append-only by
default.**

| File                  | What                                                | Lifecycle                         |
| --------------------- | --------------------------------------------------- | --------------------------------- |
| `OBSERVATIONS.md`     | Raw stream of noteworthy events from heartbeats     | Pruned monthly (Ebbinghaus)       |
| `LEARNINGS.md`        | Semantic insights that survived consolidation       | Promoted to `knowledge/` or MEMORY |
| `ERRORS.md`           | Mistakes + the rule derived from each              | Persistent, never pruned          |
| `FEATURE_REQUESTS.md` | Tools/skills the bot wishes it had                  | Aggregated weekly                 |
| `knowledge-gaps.md`   | Open research targets                               | Auto-research closes them         |
| `auto-mod-log.md`     | Every self-edit to mind-files (audit trail)         | Persistent, paired with git log   |
