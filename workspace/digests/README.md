# digests/

Self-written reflections at three cadences. **Bot writes here.**

- `daily/YYYY-MM-DD.md` — end-of-day narrative, ≤500 words, appended
  by heartbeat at the configured end-of-day hour.
- `weekly/YYYY-WW.md` — Sunday late: scan the week's daily digests +
  `learnings/`, propose mind-file updates, score progress on `goals/`.
- `monthly/YYYY-MM.md` — 1st of month: Ebbinghaus consolidation. Promote
  stable insights to `knowledge/` or MEMORY.md. Archive trivia from
  OBSERVATIONS.md. Score meta-goals.

The bot can read these files freely. The user can `git log` them to
see how the bot's thinking evolved over time.
